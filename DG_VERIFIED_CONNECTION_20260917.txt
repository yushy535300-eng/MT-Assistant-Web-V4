ANDROID APP MODE (preferred for DG):
- The app launches the real one-time DG direct1 URL in an attached hidden WebView.
- DG itself resolves direct1 -> index, chooses type/WSS, calculates sign and performs its protobuf bootstrap.
- Because the WebSocket is created by the real DG page, the WebView sends the real DG Origin.
- A document-start hook mirrors received DG binary frames to the outer MT UI; it does not replace DG's own connection.
- The outer UI decodes PublicBean and reuses the existing TableCard/RoadGrid.

NORMAL BROWSER MODE:
- Uses the server relay.
- Server now resolves the dynamic launch URL and uses the exact vendor type->WSS mapping.
- Browser-direct fallback was removed because normal browser JS cannot override WebSocket Origin.
